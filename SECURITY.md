# Security Policy

This project is pre-production and does not provide authentication, encryption,
or a hardened exchange protocol. Do not expose the example UDP path to
untrusted networks.

Report suspected vulnerabilities privately through GitHub's security advisory
flow for the repository. Include affected revision, platform, reproduction,
impact, and whether unsafe code or FFI is involved. Do not include secrets,
customer order flow, or proprietary SDK material in a public issue.
